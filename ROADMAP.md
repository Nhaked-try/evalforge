# Roadmap

- [ ] More built-in benchmarks: TruthfulQA, HellaSwag, ARC, MMLU-Pro

## Planned
- [ ] CI/CD integration template (GitHub Actions eval gate)

## Philosophy

I'm building what I need. If you need something specific, open an issue or PR. I prioritize features that help indie devs and small teams evaluate models without vendor lock-in.
